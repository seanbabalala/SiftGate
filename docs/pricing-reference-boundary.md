# Pricing reference-use and provenance boundary

## Independent implementation and rights

Design comparisons do not grant permission to copy another implementation. The
reviewed external reference is rights-reserved; direct code reuse requires prior
written authorization. Its internal repository identity, snapshot and detailed
comparison evidence are maintained in restricted engineering records, not in
customer documentation. This summary does not replace required attribution or
license notices; the Gateway's existing MIT license and notices remain unchanged.

The Gateway implements its own metering dimensions, tier selection, quantity
breakdowns, exact arithmetic, asynchronous settlement and administration workflow.
No reference source directory, private package or service is a runtime dependency.
Retail balances, private contracts, discounts and commercial margins are not
imported. Public examples use synthetic prices and fixtures.

## Review limitations

Source similarity and function-shape review found no newly introduced protected
reference implementation within the inspected scope. Pre-existing similarities
were recorded separately rather than claimed as new authorship. This is a bounded
engineering review, not proof of universal originality or a legal opinion.
Any future direct reuse needs a separate rights and attribution review.
