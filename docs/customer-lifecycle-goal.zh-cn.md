# 首次激活与身份生命周期：公开验收标准

受管客户安装使用一次性激活码，由安装所有者设置管理员密码；不存在厂商统一默认密码。
直接源码启动与已有 legacy 配置是不同入口，不应套用受管安装的激活步骤。

- 激活码短期、单次使用、绑定实例，不进入日志、URL 或公共支持包。
- 并发激活必须原子化；已有身份不能因数据缺失被静默重新认领。
- 修改密码需要重新认证；恢复是重建访问能力，不是找回明文原密码。
- 管理会话撤销不得重置业务 Key、供应商设置、计价数据或请求记录。
- 企业登录复用明确配置的身份系统，不提供未经配置的邮件找回或自动 MFA 承诺。
- 前端遵守七语言、键盘和窄屏可用性，保留既有官方 Logo。
