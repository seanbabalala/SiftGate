# SiftGate 产品化：第一次能用，下一次敢更

这是一份公开产品方向说明，不包含个人部署安排、内部任务授权或历史凭证操作记录。
具体已交付范围以[工程基线](BASELINE.md)和实际发行证据为准。

| 模块 | 客户体验 |
|---|---|
| Launchpad | 一次性激活码 → 自设管理员密码 → 接入首个模型 |
| Identity Center | 登录帮助、企业登录、改密与安全恢复，不影响业务 Key |
| Release Center | 版本差异、兼容性预检、维护窗口、真实进度 |
| Recovery Vault | 不只显示备份成功，还展示恢复验证和安全恢复路径 |
| Control Room | 独立执行升级，页面关闭不丢任务，不依赖正在重启的网关 |
| Fleet Console | 权限分离、审批、逐批升级、离线导入 |

## 产品原则

默认安全，客户决定何时改变运行实例。自动发现新版本不等于自动安装，
备份成功不等于恢复可用，测试通过不等于所有部署环境均获认证。
进度显示真实阶段与原因，不采用虚构百分比或无依据的零停机保证。

诊断资料应默认仅含元数据，导出前可预览，上传需要确认；不能包含密码、
令牌、真实配置、数据库或客户请求正文。品牌延续已有 Logo，不以通用图形替代。
